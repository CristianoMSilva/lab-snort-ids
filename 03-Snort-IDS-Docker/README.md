# Laboratório de Segurança Defensiva: IDS com Snort e Docker

Este repositório contém um laboratório prático focado na implementação e configuração de um Sistema de Detecção de Intrusão (IDS) utilizando o **Snort** dentro de um ambiente isolado e controlado via **Docker**.

O objetivo deste projeto é demonstrar como criar regras customizadas de segurança para monitorar, detectar e alertar sobre tráfegos específicos na rede em tempo real.

## Estrutura do Laboratório

A arquitetura do ambiente foi projetada para ser extremamente leve e automatizada, utilizando Alpine Linux e Docker Compose.

---
## Habilidades Demonstradas

* Conceitos de Redes de Computadores (Protocolo ICMP e análise de tráfego).

* Segurança Defensiva e Engenharia de Assinaturas (Criação de regras para IDS/IPS).

* DevOps & Infraestrutura como Código (Conteinerização e Orquestração com Docker).
